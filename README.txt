OFFSIDE — футбольный портал, демо-версия.

Публикация с iPhone:
1. Открой https://app.netlify.com/drop
2. Войди в Netlify, если сервис попросит.
3. Распакуй OFFSIDE-site.zip в приложении «Файлы».
4. Загрузи index.html/папку через интерфейс Netlify Drop.
5. Открой ссылку, которую выдаст Netlify.

Важно: счёты и таблицы в этой версии демонстрационные, а не актуальные.
Следующий этап — подключить реальный футбольный API. Не храни секретный
API-ключ в публичном HTML: для него нужен серверный endpoint/function.
